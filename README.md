# 服务器管家（AstrBot 插件）

我有三台 VPS，状态页、监控面板装了一堆，可真出事的时候我还是最后一个知道的——磁盘满了网站打不开，证书过期了浏览器报警，机器到期没续费直接停机，全是吃过亏才长记性。

后来想通了：我每天泡在聊天软件里，干嘛不让机器人替我盯着？这就是这个插件干的事：服务器有事，它在 QQ / Telegram 里直接喊我；没事的时候我问一句，它把状态报给我。

## 它能干什么

**问一句就查（指令）**

- `/状态` 所有服务器一览，`/状态 美国` 看单台明细
- `/流量` 本月跑了多少流量、配额还剩多少
- `/容器` Docker 容器谁在跑谁停了
- `/进程 美国` 吃内存的大户和监听的端口
- `/证书` 每个服务的 HTTPS 证书还剩几天
- `/订阅告警` 把当前群或私聊加入告警名单，`/取消订阅` 退出
- `/重启容器 美国 alist` 管理员专用，远程重启容器（要有白名单，见下）
- `/健康分` 给每台服务器打个分排个名：磁盘、内存、容器、流量、到期日都算进去，谁最惨一目了然
- `/登录` 查 SSH：最近谁登录过、被爆破了多少次、头号攻击来源是谁
- `/更新` 每台攒了多少待更新的包、安全更新几个
- `/到期` 到期清单：服务器、域名、证书汇成一张表，谁最急排最前
- `/资产` 资产总览：每台年费多少、一年总共烧多少、月均多少
- `/备份` 备份新鲜度：最新一份备份是几小时前的
- `/测通` 从服务器测国内外连通：国内通国外全断，基本就是 IP 被墙了
- `/管家帮助` 全部指令

**它还记得住事（病历本＋备忘）**

- 每次告警、恢复、重启，都会自动记进**病历本**：哪台机器哪天几点出过什么事，`/病历` 随时翻，`/病历 美国` 只看这一台。再不用靠脑子记「上次磁盘满是啥时候」
- `/记一笔 美国 10月3号续费过了，13.23 刀`——给服务器记**备忘**：续过费、换过 IP、装过什么，写下来；`/备忘 美国` 随时查。管家记性比我好

**不用问，它自己盯（后台巡检）**

- 机器宕了（探针连不上）——立刻告警，恢复了也报一声
- 磁盘超过阈值（默认 85%）
- 本月流量超过配额的 90%
- HTTPS 证书剩不到 15 天
- 服务器快到期（提前 15 天起，每天提醒一次，这个对我这种老忘续费的太重要了）
- 指定的服务挂了（探活清单里的网址打不开或 5xx）
- **监听端口变了**：突然多开一个端口，往往是出事了（被入侵、误装东西）的最早信号
- **SSH 被爆破**：10 分钟里登录失败超阈值（默认 30 次）立刻喊你，还附上头号来源 IP；平时用 `/登录` 能查最近谁登录过、失败了多少次
- 每天定点一份「服务器日报」推到订阅的会话

**看门狗（会干活的管家）**

给某个容器配上 `"watchdog": ["alist"]`，它一停，看门狗自动帮你重启，完了报你一声。一小时里重启 3 次还起不来，它就停手喊你人工处理，不会无限重启把机器拖死。注意：要守护的容器还得同时在探针的重启白名单（AGENT_RESTART_WHITELIST）里——双保险，缺一不可。

告警是状态翻转才发：坏的时候喊一次，好了报一次，不会刷屏。

还有三样不用你问、它自己会算的：

- **流量预测**：按本月已经用的速度推算月底总量，眼看要超配额，月初就提前喊你（每月每台只喊一次）
- **备份太老**：探针盯着备份目录（启动时用 AGENT_BACKUP_DIRS 指定），最新一份超过 48 小时（可调）没更新就告警——备份任务悄悄死了是最阴的坑
- **安全更新提醒**：攒了安全更新没装，每周提你一次

## 怎么装

分两半：机器人这边的插件，和每台 VPS 上的一个小探针。

### 1. 每台 VPS 装探针

探针就是 `agent/server_agent.py` 一个文件，纯 Python 标准库，不用装任何东西，Python 3.8+ 就能跑：

```bash
mkdir -p /opt/butler-agent && cd /opt/butler-agent
# 把 server_agent.py 放进来，然后：
AGENT_TOKEN=换成你的令牌 nohup python3 server_agent.py > agent.log 2>&1 &
```

默认监听 9876 端口。想开机自启就写个 systemd 服务，Restart=always 那种，很简单。

可选设置：

- `AGENT_BACKUP_DIRS=/data/backup,/mnt/bak`：要盯新鲜度的备份目录，逗号隔开

两个可选设置：

- `AGENT_PORT`：换端口
- `AGENT_RESTART_WHITELIST=alist,emby`：允许远程重启的容器名单，逗号隔开。不设这个，重启功能在这台机器上就是关的——我故意这么设计的，远程重启这种口子，宁可麻烦不能裸奔

⚠️ 令牌一定要设。探针端口别对全网裸奔，能加防火墙白名单就加，只放行机器人所在机器的 IP。

### 2. AstrBot 装插件

把这个仓库放进 AstrBot 的 `data/plugins/` 目录（或在插件市场里从仓库地址安装），重载插件，然后在插件配置里填：

**servers**（你的服务器清单，JSON 数组）：

```json
[
  {"name": "美国", "agent": "http://1.2.3.4:9876", "expires": "2027-10-03", "traffic_quota_gb": 1000},
  {"name": "日本", "agent": "http://5.6.7.8:9876"}
]
```

每台就四样：`name` 你顺口的名字，`agent` 探针地址，`expires` 到期日（可不填），`traffic_quota_gb` 每月流量配额 GB（可不填）。单台令牌跟全局不一样的话，再加个 `"token": "xxx"`。

**services**（要探活的服务，JSON 数组）：

```json
[
  {"name": "博客", "url": "https://blog.example.com"},
  {"name": "网盘", "url": "https://pan.example.com"}
]
```

**其他配置**：全局令牌 `agent_token`、巡检间隔、各种告警阈值、日报时间（填 `08:30` 这样）、管理员 `admin_ids`（填你的 QQ 号之类，没填的话重启容器功能直接不开）。

填完在任意会话发 `/订阅告警`，再发 `/状态` 试试，能回就是通了。

## 说明几句

- 流量统计是探针自己攒的：每次被问到就记一笔网卡计数，重启不丢（存在探针目录的 agent_state.json 里），按自然月算
- 容器重启是双保险：插件这边只有管理员能下令，探针那边只有白名单里的容器能被重启，两边都过了才执行
- 插件不存你的服务器密码，它只认探针令牌；令牌别和别的服务共用
